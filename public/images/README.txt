Put your portfolio images in these folders:

- profile/profile.jpg
  Used by the hero avatar.

- projects/
  Put project thumbnails here, for example:
  /images/projects/myhealthcare.jpg
  /images/projects/conscia.jpg

- contact/
  Put the 3 contact photos here if you want to replace the placeholders, for example:
  /images/contact/photo-1.jpg
  /images/contact/photo-2.jpg
  /images/contact/photo-3.jpg

Current code paths:

- Hero avatar: /images/profile/profile.jpg
- Project thumbnails: set the thumb field in src/components/Projects.tsx
- Contact fan photos: replace the placeholders in src/components/Contact.tsx
